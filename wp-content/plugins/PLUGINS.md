# Installed plugins

40 popular WordPress plugins installed under `wp-content/plugins/`.

Every plugin is the official upstream code, taken from each project's own GitHub
repository: the built release zip attached to the latest GitHub release where the
project publishes one, otherwise the repository tree at the latest release tag
(only for plugins that are deployable as-is, i.e. that need no `composer install`
or asset build step).

> Note: `downloads.wordpress.org` is not reachable from the environment this was
> installed in, so the plugin directory zips could not be used as the source.

Plugins are installed, not activated — activate the ones you need from
**Dashboard → Plugins**. The three SEO plugins (Yoast SEO, Rank Math, All in One
SEO) and the caching plugins (W3 Total Cache, WP Super Cache, LiteSpeed Cache)
overlap with each other; activate only one of each group.
